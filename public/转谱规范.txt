随奏 · Codex 转谱规范 v1

把图片或 PDF 与本规范交给 Codex，要求逐小节读取，不确定的音符先标记并核对，不猜音。输出 UTF-8 的「曲名.piano.json」。软件本身不连接 Codex API，也不包含图片识谱服务。

最小示例：
{
  "version": 1,
  "title": "我的曲谱",
  "composer": "",
  "bpm": 90,
  "timeSignature": [4, 4],
  "hands": {
    "left": [
      {"beat": 0, "notes": [{"midi": 48, "beats": 2}, {"midi": 52, "beats": 2}, {"midi": 55, "beats": 2}]}
    ],
    "right": [
      {"beat": 0, "notes": [{"midi": 60, "beats": 0.5}]},
      {"beat": 0.5, "notes": [{"midi": 62, "beats": 0.5}]}
    ]
  }
}

beat：从全曲 0 开始的四分音符拍位置，包含休止占用的时间。
beats：音长，以四分音符为 1 拍。全音符 4，二分 2，四分 1，八分 0.5，十六分 0.25；附点乘 1.5，三连音按实际拍数填写。
midi：21–108（A0–C8），中央 C 是 60；所有调号、临时变音、八度记号必须先应用。
spelling：可选，例 C#4、Bb3，保留原谱升降拼写。
每只手每个起音时刻写一个事件；同起音的和弦写在同一 notes 数组。两只手的事件独立。
休止不写事件，通过 beat 的空隙表达；用户休止时不按键。延音线合并为一个音符，时值累加；连奏线不合并。
反复、D.C.、D.S.、跳房子必须按实际演奏顺序展开后输出。装饰音与声部交叉需要逐项确认。
timeSignature：开头拍号，例如 [12,8]；不改变 beat / beats 的四分音符单位。
pickupBeats：可选，弱起长度；大于 0 且小于第一个完整小节。弱起标为第 0 小节，完整小节从 1 开始；不补静默。
meterChanges：可选，例如 [{"beat":91.5,"timeSignature":[3,4]}] 表示第 91.5 拍开始改为 3/4。位置必须严格递增，且位于计入弱起后的原拍号小节边界；变拍不改变音符的实际时值。省略这些可选字段时兼容原来的单一拍号格式，无需拆文件。
BPM 仍以四分音符为单位；例如原谱附点四分音符＝130，填写 bpm:195。当前不支持中途变速；需在说明中标注采用的速度。
滚谱小节线、定位、拍号显示和节拍器跟随变拍；点奏的一拍按当前拍号分母计算，12/8 为八分音符、3/4 为四分音符。双曲独奏两侧各按自己的谱计拍，节拍器跟随左侧。
本版滚谱采用等拍宽布局，不还原印刷谱的排版、力度、踏板、连奏线及装饰记号。
输出后校验小节拍数、声部/左右手、调号、音域和反复，注明不确定处；可用 npm test 与应用导入、试听核验结构，真实识谱正确性仍须对照原谱。
